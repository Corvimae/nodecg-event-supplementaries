# nodecg-event-supplementaries

Various nodecg features that are useful across multiple types of events.

This bundle does not provide any interfaces; it's just dashboard controls for
various features that another bundle can use for layout implementations.

## Current features

- Start of stream countdown.
- Now Playing value read from a file (intended for use with foobar2000).
- Host name + pronouns input.
- Controls for nameplates + CTA-style lower thirds.
- Content warning toggle + message input.
